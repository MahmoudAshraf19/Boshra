# Boshra 🌿 - Your Companion on the Path of Goodness

![Boshra App Cover](assets/images/cover_quran.png) <!-- Replace with actual banner if available -->

Boshra (بشرى) is a comprehensive, elegantly designed Islamic application built with Flutter. It aims to be your ultimate companion in daily worship, providing an immersive, spiritually enriching experience with a focus on beautiful aesthetics, dynamic interactions, and multi-language support.

## 🌟 Key Features

- **📖 The Holy Quran**: 
  - Read the Quran with a physical book-like experience.
  - Interactive Ayahs with Tafsir, Recitation, and Bookmark support.
  - Listen to recitations from various renowned reciters (e.g., Mishary Alafasy, Abdul Basit, etc.).
- **🕌 Prayer Times & Qibla**:
  - Accurate prayer times with an elegant countdown to the next prayer.
  - Adhan alerts and pre-prayer notifications.
  - Precise Qibla compass using device sensors.
- **📿 Daily Azkar & Supplications**:
  - Comprehensive Azkar categorized for Morning, Evening, Sleep, and more.
  - Daily Wird tracking and interactive counters.
- **🔔 Smart Notifications**:
  - Daily Morning and Evening Azkar reminders.
  - "Message from the Quran": A daily randomly selected Ayah sent directly to your notifications.
- **🌍 Multi-Language Support**:
  - Fully localized in Arabic, English, Spanish, French, Persian, Hindi, Italian, and Urdu.
- **🎨 Modern & Adaptive UI**:
  - Beautiful Light and Dark modes.
  - Smooth micro-animations and a glassmorphism-inspired design system.
  - Dynamic "Continue Reading" and "Selected Recitation" cards that remember your last interactions.

## 🛠️ Technology Stack

- **Framework**: [Flutter](https://flutter.dev/) (Dart)
- **State Management**: Provider
- **Local Storage**: SharedPreferences
- **Audio Playback**: just_audio
- **Notifications**: flutter_local_notifications
- **Location & Sensors**: geolocator, flutter_qibla

## 🚀 Getting Started

### Prerequisites
- Flutter SDK (latest stable version recommended)
- Dart SDK
- Android Studio / Xcode for running on emulators or physical devices.

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/MahmoudAshraf19/Boshra.git
   ```
2. Navigate to the project directory:
   ```bash
   cd Boshra
   ```
3. Install dependencies:
   ```bash
   flutter pub get
   ```
4. Run the app:
   ```bash
   flutter run
   ```
